# 🌍 Terravista – Travel Booking Website

Welcome to **Terravista**, a PHP-based travel booking website designed to help users explore travel packages, make bookings, and manage their trips online.

## ✨ About the Project

Terravista is a travel booking platform that provides a convenient way for users to discover travel packages and book their preferred trips.

The project is developed using PHP, MySQL, HTML, CSS, and JavaScript.

## 🚀 Features

- 🏠 User-friendly homepage
- 🌍 Explore travel packages
- 🧳 View package details
- 📅 Book travel packages online
- 👤 User registration and login
- 🔐 User authentication
- 🎫 Booking management
- 🧾 My Trips – View booked packages
- 🚪 Secure logout functionality
- 📱 Responsive website interface

## ⚙️ Installation & Setup

1. Download or clone this repository.
2. Install XAMPP or another PHP development environment.
3. Place the `htdocs` project files inside your local web server directory.
4. Create a MySQL database using phpMyAdmin.
5. Import your database SQL backup.
6. Configure your database connection using your own private database credentials.
7. Start Apache and MySQL.
8. Open your website in your browser.

```text
http://localhost/htdocs/
```
